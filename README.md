#  Odin Recipes Project

## Overview
This project is a multi-page HTML website built as part of The Odin Project foundations course. It features a main index homepage that links out to several individual recipe pages, with navigation links connecting them all together.

## Skills Demonstrated
- Writing clean and valid **HTML5 boilerplate** code
- Structuring and linking **multiple HTML pages** using relative paths
- Utilizing semantic elements like the **`<header>`** element
- Navigating between pages using **anchor (`<a>`) tags** and `href` attributes
- Embedding images using the **`<img>` element** with `alt` text
- Organizing recipe details using **unordered (`<ul>`)** and **ordered (`<ol>`) lists**
- Formatting text using paragraphs, emphasis, and strong tags
